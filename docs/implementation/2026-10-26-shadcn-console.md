# 2026-10-26 正式控制台视觉更新

## 变更

将用户确认的中性色仪表盘方案接入正式应用。采用 Tailwind 4、shadcn/ui 基础组件、Radix Dialog 和 Lucide 图标，统一浅色/深色语义色、侧边栏、卡片、表格、表单、焦点和禁用反馈。保留完整规则编辑、分流组、生命周期、RSS 准备进度、历史证据和设置入口。

- 总览增加实际 API 驱动的在线数量、上传/下载速度、可分配容量和最近五条投递记录。汇总排除过期、未知或不可信投影，并明确有效实例数量；单实例原始数据和原因保留。
- 下载器优先显示在线实例，可筛选在线/需关注；未知任务计数不留空。历史标题支持完整提示，删除记录继续保留时间和来源。
- 异常确认窗使用焦点约束，默认聚焦取消，Escape 关闭后返回触发按钮；执行期间不可关闭或重复提交，失败信息显示在弹窗内。
- 390/768/1280 像素布局共用实际页面。移动端导航保留键盘行为，图表可横向滚动并可键盘聚焦，修复图表隐藏说明导致的页面溢出。
- 种子大小仍用十进制 GB；磁盘和累计流量用 TB；速度用 MB/s。SSE 连接判定和后台逻辑不变。
- 生产构建不再把 React 的环境常量固定为 test；该定义只保留给 Vitest。Tailwind 扫描范围限于前端源码。

## 验证

- 前端完整回归 188 项通过（27 个测试文件），包括新增的有效数据汇总、筛选、弹窗焦点及异步失败重试场景。
- TypeScript 项目检查与 Vite 生产构建通过。
- 10 个实际路由 × 3 种宽度 × 深浅色的 60 组浏览器检查通过；无页面水平溢出，axe WCAG 2 A/AA、2.1 AA 自动检查无违规。该检查不替代人工可访问性审查。
- 正式部署使用本次提交对应 CI/G1 完成后产生的可验证构建；部署日志、备份及最终运行核验保留在本地 `artifacts/frontend-phase9/`。

## 边界

没有新增真实下载批次，没有开启停用的 RSS 或投递规则。页面检查使用现有服务的只读数据；写操作与异常状态由本地测试夹具覆盖，不冒充真实多机下载验收。参考站点只用于视觉方向，shadcn 的 MIT 版权及来源保留在第三方通知中。
