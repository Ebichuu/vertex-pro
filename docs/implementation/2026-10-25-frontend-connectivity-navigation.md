# 前端连接状态与窄屏导航修复

## 问题与变更

此前“已连接”仅依赖浏览器在线标志；服务端事件流没有订阅，移动端导航按钮没有操作逻辑。实际浏览器复现了服务不可用仍显示连接、导航无法折叠、390px 历史表格撑宽页面、1024px 规则列表溢出及两种主题的文字对比度问题。

- 登录后订阅同源 `/api/v1/events/stream`。收到 `stream.ready` 才显示连接，浏览器离线关闭连接，重新联网等待服务端确认。浏览器原生重连保留事件游标；`stream.reset_required` 重建连接并刷新读取模型。永久关闭时检查登录状态，重试间隔由 1 秒退避到最多 30 秒。
- 命名事件映射到对应读取查询，300ms 合并更新。每类查询同一时刻只启动一次刷新，慢历史请求不会阻塞总览。清理组件时关闭流和计时器，丢弃旧连接事件。规则编辑器和设置草稿不参与事件刷新。
- 窄屏导航支持展开、收起、Esc 返回按钮、选择入口后聚焦主要内容和跨断点调整；增加跳到主要内容链接。
- 历史表格在自身容器横向滚动；规则列表提前切换布局；修正顶部文字、状态文本、按钮和链接的主题对比度。

## 验证

- 前端原有 175 项通过；新增 SSE 回归 8 项，覆盖就绪确认、断网、失效游标、会话检查、事件洪峰、慢请求隔离和清理。原导航回归扩展为实际键盘交互。第一次全量为 182 项通过，增加独立慢查询隔离后针对性 20 项通过；最终完整结果以本提交 CI 为准。
- TypeScript 构建、Vite 生产构建通过。已同步 `web/dist` 与 Go 嵌入资源。构建仍有既有单 chunk 超过 500 kB 提示，未更改阈值。
- `go test -p 2 ./internal/webembed ./internal/httpapi ./internal/sseserver ./internal/resourcesapi -count=1` 通过。
- 无头 Edge，浅色/深色各 7 个页面 × 1440/1024/390px：共 42 次布局/axe 扫描，无页面溢出、扫描违规或页面异常。两个主题均验证事件流 503 → 重连中 → 恢复连接，Esc 焦点返回及未保存规则草稿保留。使用本机独立预览前端连接当前后端，拦截除登录以外的写请求，实际写操作为 0。汇总在 `docs/evidence/frontend-connectivity-20261025/summary.json`。
- 初次预览登录受 Origin 白名单拒绝；调整仅用于本机预览的转发配置后通过。一次并行浏览器复查在恢复阶段超时，保留日志后单独复跑通过。生产安全配置未改。该扫描只覆盖所列页面、数据和视口，不等同于完整无障碍认证或全部产品功能验收。
