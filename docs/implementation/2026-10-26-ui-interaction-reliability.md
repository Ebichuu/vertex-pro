# 2026-10-26 控制台交互边界修复

## 变更

沿用已经确认的控制台布局，本轮修复刷新、失败重试及日期和统计口径。

- 站点列表的后台刷新失败时继续展示已有数据，并保留打开的 RSS 编辑草稿。
- RSS 编辑只提交实际修改的字段。刷新带来的其他字段变化不会被旧草稿覆盖；编辑字段同时被修改或服务端版本冲突时保留草稿并提示核对。
- 站点创建成功、RSS 创建失败时保留表单，重试只创建 RSS。重试使用最新站点信息并保留其他 RSS；站点被删除时提示重新添加，保留草稿。
- 凭据引用保存失败后保留输入，允许再次失焦重试；刷新不会清掉尚未保存的输入。
- 设置页主动放弃草稿并载入最新版本时，等待期间禁用字段，避免输入随后被加载结果覆盖。普通断线重连仍保留并允许编辑草稿。
- 历史列表的发现日期和删除日期采用配置时区，与详情页保持一致；统计日界线继续为 UTC。
- 今日站点确认数只统计 `HASH_SEEN` 和 `RECONCILED_CONFIRMED`，排除没有发起新 Add 的 `ALREADY_PRESENT`。较早创建但今日确认、随后删除的任务继续计数。
