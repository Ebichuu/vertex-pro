- RSS 行新增“准备状态”，逐条展示等待准备、等待限流、获取中、重试等待、进入投递流程、未进入投递流程、历史跳过及失败；种子大小为十进制 GB。每 5 秒刷新，支持分页及读取失败重试，切换/关闭会取消旧请求。消费者租约过期不永久显示“获取中”。只返回安全标题、大小、时间及错误码，不返回源 URL、source key 或凭据。
- 迁移 `0023_preparation_progress.sql` 增加准备起始时间、目标不可用起始时间及有界快照冲突重试计数，不重置去重或旧批次。
- 快照更新与 Begin 重查碰撞时，最多 3 次使用 5 ms 本地重试，之后仍退避 100 ms；其他失败保持原退避。重试只重新检查未发送队列，不能重发 HTTP。
