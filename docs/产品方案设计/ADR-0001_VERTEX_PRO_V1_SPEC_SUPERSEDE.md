# ADR-0001：Vertex Pro V1 规范承接与替代边界

- Status: PROPOSED
- Date: 2026-08-24

## 决策

本地开发阶段继续以现有 RC8 设计与实施合同作为输入，不对既有规范执行 supersede，不改变产品行为、状态、存储、API 或安全边界。

只有在 `G1_PASS && G2_PASS && A24_PASS && C1_PASS` 全部成立后，才允许将本 ADR 状态改为 `ACCEPTED`，并由后续变更明确记录被替代的规范与迁移影响。

## 当前边界

本 ADR 仅记录承接和替代条件，不代表规范已经接受、冻结或完成发布。所有未实现的数据库、API、外部适配器和真实运行链路仍保持阻塞状态。
