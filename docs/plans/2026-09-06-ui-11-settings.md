# UI-11 Settings 实施记录

- SQLite 单行设置保存七个非敏感字段；请求必须携带读取时的 revision，原子更新防止并发覆盖。前后端限制范围一致，小时保留期不得短于原始数据保留期。

- RSS 定时轮询与手动测试共享每个目标主机的请求节流和并发上限；会话有效期与统计清理保留期消费启动时的设置。
- 前端使用合同生成的类型和 API 客户端，包含加载失败重试、离线保留草稿、重连刷新、版本冲突提示、字段标签和错误关联。
